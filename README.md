# 公共施設 劣化調査ノート（v2.0）

公共施設等総合管理計画の策定に伴う劣化状況調査で、現地での写真撮影と所見メモの記録を支援するWebアプリ（PWA）です。
iPad・iPhone・Androidのブラウザで動き、データはすべて端末内に保存されます（サーバー不要・オフライン可）。
出力は既定の様式（劣化度調査票／劣化状況写真／バリアフリー状況）に合わせたExcelです。

## 調査の流れ

1. **出力・設定** → 自治体名・調査名・記入者を入力
2. **調査対象（建物）を登録**：1件ずつ追加するか、施設リストCSVを取り込む。**調査票1枚＝1件**（複数棟で調査票を分ける場合は棟ごとに登録）
3. 建物を開いて **「📷 撮影して記録」**（1枚目は自動で「全景」）
4. 記録画面で入力（自動保存）
   - **部位（調査票の区分）**：全景／屋根・屋上／外壁／内部仕上／電気設備／機械設備／外構・その他
   - **階**、**部位（詳細）**（例：パラペット立上り部）
   - **所見メモ**：劣化の状況と、それが何を意味しているか。劣化現象を選んで「例文を挿入」で定型文を入れられる。写真台帳の所見欄（15字×9行目安）に収まるかを表示
   - 撮影直後の画面に「📥 保存」ボタンが出ます。押して共有シートの「画像を保存」を選ぶと、**元の画質のまま本体の写真アプリにも保存**されます（Webアプリは自動保存できないため1タップ必要。不要なら「出力・設定」でオフ）。建物画面の「まとめて本体に保存」でも一括保存できます（こちらは圧縮後の画像）
   - 「写真から」で写真アプリの写真を取り込むと、撮影日時（EXIF）を読み取って撮影順に並べます
5. 必要に応じて **建物情報**（建築年度・構造・延床面積・階数・主な工事履歴・特記事項）と **バリアフリー** を入力
6. **Excel出力**

## v2.0 で追加した機能

- **図面から撮影**：建物画面の「図面」で、階ごとに図面（画像・PDF）を取り込みます。「📍 撮影位置を置く」をオンにして図面をタップするとカメラが起動し、撮影後に入力画面へ移ります。ピンには写真番号が付き、タップで記録を開きます。既存の記録には記録画面の「📍 図面に撮影位置を付ける」で位置を付けられます。
- **撮影位置図の出力**：図面画面の「撮影位置図を出力」で、写真番号入りのピンを描いた図面を階ごとに画像（JPEG）で保存できます。
- **部位（詳細）の候補**：部位の区分ごとの候補（`config.js` の `details`）と、この建物で使った言葉がボタンで出ます。
- **劣化の広がり**：単独／室内で複数／複数の室／建物全体。写真台帳の所見欄の最後の行に注釈（例：※建物全体でみられる）、調査票の劣化状況に【建物全体】のように入ります（`config.js` の `spreads`）。
- **一覧での出力選択**：「☑ 出力の選択」でタップするだけで出力する／しないを切り替え。すべて出力・すべて外すも可。
- **並び順**：撮影順／部位区分順／階・場所順／手動（▲▼・番号指定）。この並び順で写真番号を振り直し、Excelもこの順で出力します。
- **場所（部屋名など）**、**同じ箇所の複数写真（★で台帳に使う写真を選択）**

## Excel出力の中身

| シート | 内容 |
|---|---|
| 劣化度調査票 | 上段の基本情報（調査日＝最初の撮影日、築年数は自動計算）、部位別の「劣化状況」に各写真の所見を「・階　部位：所見（写真n）」の形で下書きとして転記。**総評・判定は空欄**（事務所で記入） |
| 劣化状況写真 | 様式どおりA4縦・1ページ3枚。写真№・撮影日・階・部位・所見。写真がない欄も枠と項目名を残して出力 |
| バリアフリー状況 | 有／無、勾配・高さ・台数、その他気づいた点 |

- 建物ごとの出力：上の3シート（シート名は様式と同じ）
- 全件出力：先頭に「調査記録一覧」、続いて建物ごとに「番号_施設名_調査票／_写真／_BF」
- 写真№は建物ごとに撮影順で 1, 2, 3…

## バックアップ・複数端末の統合

「出力・設定」→ バックアップの書き出し（写真込みのJSON）を毎日行ってください。複数人で調査した場合は、各端末のバックアップを1台で「読み込み（統合）」してから出力します。

## 施設リストCSVの形式

```
施設番号,施設名,棟名,建築年度,構造,延床面積,階数,所在地
12,図書館・歴史資料館,,2000,RC／S造,3899.27,2,○○町1-1
21,第一小学校,体育館,1985,S造,1200,1,○○町2-2
```

「施設番号」「施設名」以外は任意。1行が調査票1枚。Excelの「CSV」保存（Shift_JIS／UTF-8どちらも可）で作れます。

## 項目のカスタマイズ

`config.js` で、部位区分・階の候補・劣化現象と例文・所見欄の文字数／行数・判定基準の凡例・バリアフリー項目を変更できます。
変更後は `sw.js` の `CACHE_VERSION` を上げると、ホーム画面に追加済みの端末にも反映されます。
様式のレイアウト（列幅・行高・罫線・フォント）は `export.js` にあります。

## 動かし方

### Macで試す
```
cd このフォルダ
python3 -m http.server 8000
```
ブラウザで http://localhost:8000 を開く。

### iPad・iPhoneで使う
カメラ撮影・オフライン動作・データ保持のため、**HTTPSで公開**する必要があります。中身は静的ファイルだけなので、以下のいずれかで公開できます（調査データは端末内にしか保存されず、公開先には送られません）。

- GitHub Pages（リポジトリにpush → Settings → Pages）
- Cloudflare Pages / Netlify（フォルダをドラッグ＆ドロップ）

公開URLをSafariで開き、共有ボタン →「ホーム画面に追加」するとアプリとして使え、圏外でも起動します。

## 注意

- データはブラウザ（端末）内に保存されます。Safariの「履歴とWebサイトデータを消去」や長期間未使用による自動削除で消えることがあるため、**バックアップの書き出しを習慣に**してください。
- アプリ内とExcelの写真は長辺1280px（JPEG品質78%、1枚約150〜300KB）に圧縮します。写真台帳の写真枠（印刷で約9cm幅）を300dpiで印刷できる大きさです。`config.js` の `image` で変更できます。
- 部位（区分）が未設定の写真は、写真台帳には載りますが調査票の劣化状況には転記されません（出力時に枚数を表示）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html | 画面とスタイル |
| app.js | 画面・保存・バックアップ・CSV取込 |
| export.js | 様式どおりのExcel生成 |
| config.js | 部位・劣化現象・例文・バリアフリー項目などの設定 |
| sw.js / manifest.webmanifest | オフライン動作・ホーム画面追加用 |
| plans.js | 図面・撮影位置・撮影位置図 |

| vendor/pdf.min.js, pdf.worker.min.js | PDF読込ライブラリ（PDF.js 3.11, Apache-2.0。図面のPDF取込時のみ使用） |
| icons/ | アプリアイコン |
| サンプル出力_劣化調査.xlsx | テストデータでの出力例 |
